# [Insert in a Sorted List](https://www.geeksforgeeks.org/problems/insert-in-a-sorted-list/1)
## Easy
Given a linked list sorted in ascending order and an integer called key, insert data in the linked list such that the list remains sorted.
Examples:
Input: LinkedList: 25-&gt;36-&gt;47-&gt;58-&gt;69-&gt;80, key: 19
Output: 19-&gt;25-&gt;36-&gt;47-&gt;58-&gt;69-&gt;80Explanation: After inserting 19 the sorted linked list will look like the one in the output.
Input: LinkedList: 50-&gt;100, key: 75
Output: 50-&gt;75-&gt;100Explanation: After inserting 75 the sorted linked list will look like the one in the output.
Constraints:1 &lt;= size of linked list &lt;= 1061 &lt;= data of nodes &lt;= 106
